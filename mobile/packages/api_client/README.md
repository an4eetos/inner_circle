# inner_circle_api

Dart client for the Inner Circle API, generated from `api/openapi.yaml` with
openapi-generator (`dart-dio`, `json_serializable`). Regenerate from the repo root:

```bash
make gen-dart
```

Everything under `lib/` is generated. `pubspec.yaml`, `build.yaml` and this README are
maintained by hand (listed in `.openapi-generator-ignore`).
